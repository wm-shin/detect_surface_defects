# 설계 결정

강의 자료(`lecture_materials/`)대로 작업하다가 자료와 다르게 정했거나 자료에 없어서 새로 정한 것이 생길 때만 여기에 적는다. 주제별로 현재 유효한 결정만 두고, 바뀌면 항목을 고쳐 쓰고 날짜를 남긴다. 이전 내용은 git 이력으로 본다.

## 데이터

- `data/`는 논문 최종 데이터셋(`yolo_seg_3_clean_v4_2`, 주석·분할·무결성 점검 완료)을 그대로 받은 것이다. 원본 ID 기준으로 split을 비교하니 `URT017_2020_02_08_001_24512` 하나가 train(원본 1장 + 증강본 54장)과 test(Roboflow 내보내기본 1장, 같은 사진을 따로 주석)에 같이 있었다. 강의 자료(본 강의 25쪽)는 이 데이터셋에 누수가 없다고 전제하므로 자료에 없는 결정이다. 테스트셋은 논문 조건 그대로 두고 train에서 55장(영상·라벨)을 지운다. (2026-11-05)
- train 안에 내용(md5)이 완전히 같은 영상이 27묶음(2장짜리 26, 3장짜리 1) 있었다. 증강 스크립트가 같은 회전·뒤집기를 같은 파일에 두 번 적용해 번호만 다르게 저장한 것이고 라벨도 같다. 강의 본 자료 25쪽 "중복 영상 검토(같은 샘플의 이중 계산 방지)"에 따라 묶음마다 이름순 첫 파일만 남기고 28장을 지운다. val·test에는 중복이 없다. (2026-11-07)
- train의 증강본 63장(원본 `URT020_2021_01_12_002_779` 2장, `URT020_2021_03_05_002_20650` 27장, `URT020_2021_04_03_001_2914` 34장)은 영상 파일이 0바이트다. 다시 받아도 같아서 배포본 자체가 빈 것으로 본다. 영상·라벨을 함께 지운다. 세 원본의 나머지 파일(각 61·19·1장)은 train에 남으므로 원본 단위 분할은 유지된다. val·test에는 없다. (2026-11-07)
- 제외한 파일은 모두 `docs/excluded_train_files.csv`(열 `stem`, `reason`)에 둔다. 지금 146행 = URT017 55 + 중복 28 + 빈 파일 63. 그 결과 train 3,890장·val 40장·test 40장. 데이터를 다시 받으면 목록대로 다시 지운다: `cd data && for s in $(tail -n +2 ../docs/excluded_train_files.csv | cut -d, -f1); do rm -f images/train/$s.jpg labels/train/$s.txt; done`. 지워졌는지는 `scripts/check_data.py`로 확인한다. (2026-11-05, 2026-11-07 중복 28장·빈 파일 63장 추가)
  - **최종 리포트에 반드시 넣는다.** 데이터 절(규모가 논문의 4,036장과 다른 이유: 누수 55장 + 중복 28장 + 빈 파일 63장 제외, 클래스별 인스턴스 수도 바뀜)과 한계·재현 정보 절(강의 자료가 누수 없음으로 소개한 데이터셋에서 train–test 겹침 1건·중복 27묶음·빈 파일 63장을 발견해 제외했다는 사실과 제외 목록 파일)에 적는다.
  - 원본 ID는 파일명에서 `_aug` 앞부분을 취하고, Roboflow 접미사 `_jpg.rf.<해시>`는 먼저 뗀다. 강의 2주차 12쪽의 `stem.split("_aug")[0]`에 접미사 제거를 더한 것.

## 작업 방식

- 스크립트마다 `scripts/mermaid/{스크립트 이름}.md`에 입출력·함수 흐름·자료형을 Mermaid 그림으로 둔다. 스크립트 옆에 두어 코드와 같이 보게 한 것(pcm-formulations의 `docs/mermaid/`와 다름). 스크립트를 추가하거나 입출력·함수 구조를 바꾸면 같은 턴에 그림을 고친다. 첫 대상은 `scripts/check_data.py`. (2026-11-06)
  - 형식: 하는 일을 단계 번호·설명 표로 먼저 적고, 같은 번호를 쓴 흐름 그림 하나, 필요하면 세부 규칙 그림, 마지막에 출력 예. 담당 함수 이름은 표가 아니라 그림의 상자에 넣는다(표의 열은 안 보게 됨). 변수 이름·자료형은 그림에 넣지 않는다(코드보다 읽기 어려워짐). (2026-11-06)
